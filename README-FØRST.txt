TIDSKAPSLEN HJEMMESIDE – VERSION 01 GRUNDDESIGN

Dette er et HELT NYT og RENT projekt.

Sådan bruger du pakken:
1. Pak ZIP-filen ud.
2. Kopiér ALLE filer og mapper fra den udpakkede mappe ind i din tomme mappe:
   Tidskapslen-Hjemmeside
3. Åbn Tidskapslen-Hjemmeside i VS Code.
4. Åbn Terminal i VS Code.
5. Kør:
   npm install
6. Når den er færdig, kør:
   npm run dev
7. Åbn adressen Vite viser, normalt http://localhost:5173/

Vigtigt:
- Dette projekt er helt adskilt fra Tidskapslen Studio.
- Vi bruger fremover navnene Version 01, Version 02 osv.
- Version 01 bruger det rigtige Tidskapslen-logo i headeren.
- Hero-sektionen bruger et produktbillede i stedet for et kæmpe logo.
- Ingen gamle sprint-backupmapper er med.
